Nodearr connects your Arr apps to libraries shared by people you trust. Each person runs their own node and chooses what to share. This guide takes you from installation to a file imported by your Arr app.

## Before you start

- Have a supported library app running: [Sonarr](https://sonarr.tv/), [Radarr](https://radarr.video/), [Lidarr](https://lidarr.audio/) or [Whisparr](https://whisparr.com/). You will need its address and API key, found in that app under **Settings > General**.
- Choose a machine where Nodearr can read your libraries and your Arr apps can read its completed downloads. Running Nodearr alongside your apps usually makes this easier.
- To finish pairing and try a transfer, have a friend with Nodearr running and at least one file to share. You can install Nodearr and connect your apps before they are ready.

[Prowlarr](https://prowlarr.com/) is optional. Connect each library app directly to Nodearr even if you already use Prowlarr.
